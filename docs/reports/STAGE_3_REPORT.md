## Architecture, compilation and node verification

The pure engine imports only contracts/domain/validation. React, React Flow, Zustand, storage, browser clocks and worker transport stay outside it. The scheduler receives monotonic clock, task-queue yield, publication and cancellation/context ports. Registry dispatch is a literal node-type switch; test handlers are injected only into isolated fixtures. The host captures one immutable snapshot identified by sessionId + semanticRevision + fresh UUID runId. Presentation changes preserve accepted results; semantic changes clear them and terminate the worker. Stale traffic is discarded and counted locally.

Compilation reuses canonical validation and the existing iterative graph algorithms rather than inventing a second schema or topology authority. Full readiness requires a trigger, a statically reachable Output and configured reachable nodes. Disconnected null drafts remain warnings/skips. The worker independently repeats compilation; no operation runs on a failed plan. Scheduling is sequential UUID Kahn order, independent of serialized order, positions, animations or promise settlement.

## Protocol, state machine, cancellation and budgets

Both directions use strict version-1 messages with identity tuple, contiguous sequence and fresh control request IDs. The host verifies acknowledgements, exact static node order, active input/port references and node dispositions before reducing current messages. Unknown/rebound payload IDs, replay/gaps, premature completion, wrong ports, malformed/oversized current traffic and worker crashes fail safely. Old identities cannot populate a new run, reopened session or semantic undo. Reset/switch/disposal release timers, handlers, workers and payload registries. Page-cache suspension clears the active run without permanently disabling future Run.

Payload-record messages are tentative. No staged value appears in inspection or activates descendants until completion validates the full result, port set and accounting. Node failure/cancellation discards staging and retains earlier accepted outputs as partial. The diagnostic ring stores metadata only, never payload contents, display names or raw native errors. Final metadata and payloads are kept separately. Output inspection names come from the validated captured configuration.

All unchanged document/node/edge/depth/value/string/path budgets apply before compilation. Runtime enforces per-payload 256 KiB, cumulative produced and unique-retained 16 MiB, 300 attempted operations, 1,000 ms per operation, 30,000 ms active and 600,000 ms wall lifetime. Conditions charge forwarded emitted bytes; Output reuses the reference. Tests cover exactly 300 operations and rejection of a 301st graph node; cumulative bytes fail even when one payload reference is forwarded repeatedly. Skips do not consume steps, and skipped regions yield within 32 records.

Host watchdogs are independent of worker progress. They check deadlines before accepting messages and on visibility return, arm operation time on accepted node-start, exclude acknowledged pauses from active time and include them in wall time. Fake-clock cap/cap+1 tests complement real unresolved and synchronous-blocked worker tests. Stop preserves terminal completion/failure; cancellation cannot revive an old run. Duplicate controls either no-op or reject INVALID_TRANSITION.

Results report finite nonnegative wall/active/paused/compile intervals and safe counts. Host timing replaces terminal UI timing from its own clock; it never subtracts window and worker absolute timestamps. Handler durations are measured within the worker. Schema construction for response messages is lazy on the host, so the receiving worker no longer initializes response-only validators. Strict schemas and limits are unchanged.
