## Confirmed defect and minimal correction

**D-FB-01 — High usability defect, responsive Canvas below 1024 px.** The outer `.canvas-frame` measured 520 px, while `.react-flow` and its renderer measured 0 px. The earlier rectangular node visibility assertion did not detect clipping by a zero-height renderer; agent review of the blank screenshot did. A minimum height on an auto-sized parent did not give the percentage-height child a definite containing block.

The existing narrow media query now gives `.canvas-frame` `height: 520px` and `flex: none`, retaining its existing minimum. Wide-screen layout and graph/engine behavior are unchanged. The regression checks the internal renderer height before/after interactions and a node's intersection with the canvas. All five widths passed after rebuilding. The pre-fix zero-height measurements, raw results and traces remain retained. There was no data reset or subsystem rewrite.

The new verification also exposed three fixture/evidence issues, handled separately from application defects:

- A failed-node selector matched both the graph list and inspector. It now names the intended graph-list scope.
- A horizontal SVG path has width/stroke but zero geometric height. The check now verifies nonzero path extent, visible style, painted stroke and stroke width; screenshots remain part of the evidence.
- A short production execution can finish before a user Pause is delivered. The initial assertion contradicted EXECUTION_MODEL's exhaustion-wins rule. The corrected test preserves completion, requires all 270 executable records terminal, and a separate delayed real-worker case still strictly requires pause/no advancement/Resume. No scheduler behavior, assertion on that paused worker, duration limit or performance target was weakened.

Default Playwright screenshot clipping did not capture the visible content correctly at native browser zoom; those blank captures remain preserved and are not visual proof. Direct compositor screenshots without a CSS clip provide the zoom images linked above. Chrome's zoom selector, DPR ratio, unchanged physical bounds and actual successful interactions provide independent proof of real browser zoom.
